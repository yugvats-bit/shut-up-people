# Shut up people — Ho gaya tera

Web prototype: the moment someone starts talking, it talks over them with three lines:

1. **Ho gaya tera** (Hindi)
2. **bas kar yaar** (Hindi)
3. **someone take this human away from me** (English)

Open `index.html` in a browser (or serve the folder), click **Start listening**, and allow the microphone. Use headphones so it doesn't hear itself.

Hindi lines use your browser's Hindi (hi-IN) voice if one is installed; Chrome and Edge usually have one.
